# MoveMan PRD

## 1. 문서 개요

- 제품명: MoveMan
- 대상 파일: `MoveMan.py`
- 대상 에셋: `animation_sheet.png` (소년 스프라이트 시트), `TUK_GROUND.png` (배경)
- 실행 환경: Python, Pico2D
- 문서 상태: 구현 전 개발 요구사항

## 2. 제품 설명

`LEC10_HandlingInputs`의 소년 캐릭터를 방향키 입력으로 이동시키는 간단한 2D 프로그램을 만든다. 화면에는 `TUK_GROUND.png`를 배경으로 표시하고, `animation_sheet.png`에서 캐릭터 스프라이트를 표시한다. 캐릭터가 화면 경계를 벗어나지 않도록 이동 범위를 제한하며, 좌우 이동 방향과 캐릭터의 시선 방향을 일치시킨다.

## 3. 목표와 제외 범위

### 목표

- 방향키로 캐릭터를 상·하·좌·우로 이동시킨다.
- `animation_sheet.png`의 소년 스프라이트를 사용한다.
- `TUK_GROUND.png`를 게임 화면의 배경으로 사용한다.
- 좌우 이동 시 캐릭터가 이동 방향을 바라보도록 한다.
- 캐릭터 전체가 화면 안에 머물도록 이동 경계를 처리한다.
- Pico2D로 구현하고 창 닫기 및 ESC 입력으로 정상 종료한다.

### 제외 범위

- 적, 충돌, 점수, 아이템, 게임 진행 규칙 및 승패 처리
- 사운드, 메뉴, 설정 화면, 네트워크 기능
- 스프라이트 시트나 배경 에셋의 편집 및 자동 분석
- 별도 모듈이나 외부 설정 파일의 추가

## 4. 사용자 시나리오

1. 사용자가 `MoveMan.py`를 실행한다.
2. 프로그램이 Pico2D 창을 열고 배경과 소년 스프라이트를 표시한다.
3. 사용자가 방향키를 입력하면 캐릭터가 해당 방향으로 이동한다.
4. 왼쪽 또는 오른쪽으로 이동하면 캐릭터의 시선 방향도 이동 방향에 맞춰 바뀐다.
5. 캐릭터가 화면 가장자리에 도달하면 더 이상 화면 밖으로 이동하지 않는다.
6. 사용자가 ESC 키를 누르거나 창을 닫으면 프로그램이 종료된다.

## 5. 기능 요구사항

### FR-1. 실행 및 에셋 로드

- Python과 Pico2D를 사용한다.
- 실행 진입점은 `MoveMan.py`로 한다.
- 캐릭터 이미지는 같은 폴더의 `animation_sheet.png`를 사용한다.
- 배경 이미지는 같은 폴더의 `TUK_GROUND.png`를 사용한다.
- 에셋 경로는 현재 작업 디렉터리에 의존하지 않도록 스크립트 위치를 기준으로 결정한다.
- 이미지 로드에 실패하면 에셋 경로와 원인을 확인할 수 있도록 오류를 드러내고 정상적인 오류 종료를 한다.

### FR-2. 화면과 렌더링

- 배경을 먼저 그리고 캐릭터를 그려 캐릭터가 배경 앞에 표시되도록 한다.
- 기본 화면 크기는 배경 에셋의 크기에 맞춘다. 제공된 예제에서 확인되는 기준 크기는 1280 x 1024 px이며, 실제 에셋 크기와 다르면 배경에 맞춰 조정한다.
- 화면을 반복 갱신하고 Pico2D 이벤트를 처리해 입력과 창 닫기 요청에 응답한다.
- 캐릭터는 스프라이트 시트의 소년 프레임을 사용한다. 프레임 좌표와 크기는 실제 에셋을 확인해 정하며, 캐릭터가 잘리거나 주변 이미지가 섞이지 않도록 한다.

### FR-3. 방향키 이동

- 위, 아래, 왼쪽, 오른쪽 방향키 입력에 각각 대응하는 방향으로 캐릭터를 이동시킨다.
- 상하좌우 이동은 화면 좌표계에 맞게 처리한다. 특히 위쪽 입력은 화면의 위쪽으로, 아래쪽 입력은 화면의 아래쪽으로 이동한다.
- 이동 단위와 입력 처리 방식은 코드에서 읽고 조정할 수 있게 둔다.
- 한 번에 여러 방향키가 입력되는 경우의 동작은 필수 범위가 아니다. 기본 구현은 방향키 하나씩의 이동을 기준으로 한다.

### FR-4. 좌우 시선 방향

- 오른쪽으로 이동할 때 캐릭터는 오른쪽을 향한다.
- 왼쪽으로 이동할 때 캐릭터는 왼쪽을 향한다. 시트에 왼쪽을 향한 프레임이 따로 없다면 스프라이트를 수평 반전해 표현한다.
- 시선 방향 변경으로 캐릭터의 위치나 화면 경계 처리가 달라지지 않아야 한다.

### FR-5. 화면 경계

- 캐릭터가 화면의 어느 가장자리에도 벗어나지 않도록 이동 위치를 제한한다.
- 경계 계산에는 캐릭터의 중심점만이 아니라 실제로 그려지는 프레임의 너비와 높이를 반영한다.
- 경계에 도달한 방향으로 더 입력해도 캐릭터가 화면 밖으로 이동하지 않는다.

### FR-6. 종료 처리

- 창 닫기 이벤트와 ESC 키를 종료 입력으로 처리한다.
- 종료 입력을 받으면 메인 루프를 빠져나와 Pico2D 캔버스를 닫는다.

## 6. 비기능 요구사항

- 요구된 프로그램은 `MoveMan.py`를 중심으로 구현한다.
- 이미지 경로에 사용자별 절대 경로를 하드코딩하지 않는다.
- 이동 처리, 이벤트 처리, 렌더링 및 종료 흐름을 읽기 쉬운 구조로 작성한다.
- 프레임 좌표, 표시 크기, 이동 단위 등 조정이 필요한 값은 코드에서 쉽게 찾을 수 있도록 모아 둔다.
- 루프가 실행되는 동안 입력과 종료 이벤트를 지속해서 처리한다.

## 7. 기본 가정 및 결정 사항

- 창 크기는 제공된 배경 예제의 기준인 1280 x 1024 px를 우선 사용하되, 실제 `TUK_GROUND.png` 크기를 확인해 맞춘다.
- 제공된 `move_character_with_key.py`가 키 입력마다 위치를 10픽셀 변경하는 예제를 사용하므로, 별도 수업 기준이 없다면 이동 단위의 초기값은 10픽셀로 한다.
- 스프라이트 시트의 프레임 좌표와 캐릭터 표시 크기는 구현 전에 이미지를 확인해 결정한다. 확인되지 않은 좌표나 프레임 수를 미리 고정하지 않는다.
- 좌우 반전은 왼쪽을 향하는 프레임이 시트에 별도로 없는 경우에만 사용한다.
- PRE_PRD에서 요청한 작업 브랜치 이름은 `MoveManLeftRightUpDown`이다. 구현 작업은 해당 브랜치에서 진행한다.
- 구현은 한 번에 몰아서 완료하기보다 기능 단위로 나누며, 대략 15회의 커밋을 목표로 한다. 각 커밋 제목은 한글로 작성한다.

## 8. 완료 및 검수 기준

- [ ] `MoveMan.py`를 실행하면 Pico2D 창이 열린다.
- [ ] `animation_sheet.png`의 소년과 `TUK_GROUND.png` 배경이 표시된다.
- [ ] 방향키를 누르면 캐릭터가 해당하는 상하좌우 방향으로 이동한다.
- [ ] 좌우 이동 방향과 캐릭터의 시선 방향이 일치한다.
- [ ] 캐릭터의 어떤 부분도 화면 경계를 벗어나지 않는다.
- [ ] 경계에서 바깥쪽 방향키를 추가 입력해도 캐릭터는 화면 안에 머문다.
- [ ] 창 닫기와 ESC 키 입력으로 프로그램이 정상 종료되고 캔버스가 정리된다.
- [ ] 프로젝트 폴더 밖을 현재 작업 디렉터리로 두고 실행해도 같은 폴더의 이미지 에셋을 찾는다.
- [ ] 구현 커밋은 `MoveManLeftRightUpDown` 브랜치에 한글 제목으로 기능 단위로 나누어 기록한다.
